AI Travel Planning System

A real-world multi-agent AI system built with LangGraph that plans complete trips automatically — flights, hotels and itinerary — through 4 collaborating agents.

Source Code

Use Case & Problem Solved

Planning a trip usually means juggling multiple tabs — flight search, hotel comparisons, and manually stitching together a day-by-day itinerary. This project automates that entire workflow using a coordinated team of AI agents built on LangGraph, each responsible for one part of the trip-planning process. A single natural-language prompt like "Plan a complete 7 day Japan trip including flights, hotels and sightseeing under 2 lakhs" is enough for the system to research, plan and generate a ready-to-use travel plan.


Key Features:

  • Flight Search Agent using real-time flight data
  • Hotel Search Agent powered by live web search
  • Itinerary Planning Agent generating day-by-day plans
  • Final Response Agent that consolidates everything into one answer
  • Long-term conversation memory using PostgreSQL
  • Streamlit web interface for an end-to-end chat experience

Project Description

The system is orchestrated as a LangGraph state machine. A shared TravelState object flows through four nodes in sequence: the Flight Agent fetches live flight data via the AviationStack API, the Hotel Agent runs a Tavily-powered web search for the best hotel options, the Itinerary Agent (running on Groq's Llama 3.3 70B) turns those results into a structured day-by-day plan, and the Final Response Agent combines flights, hotels and itinerary into one coherent recommendation.


Every conversation is checkpointed to PostgreSQL using LangGraph's Postgres checkpointer, so the system remembers prior context per user thread — the same compiled graph powers both a terminal interface and a Streamlit web app, giving users a choice between a quick CLI test and a full browser-based planner.


Key Concepts Used:
• LangGraph state graphs & multi-agent orchestration
• LLM-powered reasoning with Groq (Llama 3.3 70B)
• Real-time API integration (flights & web search)
• Persistent memory with PostgreSQL checkpointing
• Streamlit for the interactive front-end
